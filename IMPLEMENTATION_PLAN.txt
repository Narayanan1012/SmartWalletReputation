PROJECT OVERVIEW
--------------------------------------------------------------------------------
Product: Wallet & Contract Reputation Explorer
Goal: Allow users to inspect an EVM address and understand active token approvals,
smart contract relationships, and security signals via an explainable evidence chain:
  Wallet -> Token Approval -> Spender Contract -> Security Signal -> Potential Exposure

Scope: Read-only. Ethereum & Base. Zero fund movement, zero private keys.

--------------------------------------------------------------------------------
SEQUENTIAL MILESTONES
--------------------------------------------------------------------------------

MILESTONE 1: Backend Health Check
- What: Initialize backend/ folder with package.json, Express, CORS, and GET /api/health.
- Test: curl http://localhost:4000/api/health -> {"status": "ok"}

MILESTONE 2: Address Analysis Endpoint Skeleton
- What: Create POST /api/analyze route accepting {"address": "0x..."} with EVM regex validation.
- Test: curl -X POST -H "Content-Type: application/json" -d '{"address":"0xd8dA6BF26964aF9D7eEd9e03E53415D37aA96045"}' http://localhost:4000/api/analyze

MILESTONE 3: Alchemy Connection & Basic Read
- What: Configure Alchemy SDK / RPC connection with environment variables. Test simple query (e.g. eth_blockNumber).
- Test: Isolated script querying Ethereum block height via Alchemy.

MILESTONE 4: Address Activity & Transfer / Approval Events
- What: Fetch token transfer / approval logs for target wallet using Alchemy APIs (alchemy_getAssetTransfers).
- Test: Query vitalik.eth and print raw token activity.

MILESTONE 5: Approval Discovery (Multi-Token)
- What: Scan for Approval events (Approval(address owner, address spender, uint256 value)) across tokens.
- Test: Output discovered spenders and tokens for test wallet.

MILESTONE 6: Current Allowance Verification
- What: Check current live allowance via ERC20 allowance(owner, spender) view call to confirm allowance is still active.
- Test: Verify live allowance for known spender vs historical approval.

MILESTONE 7: GoPlus Contract Security Lookup
- What: Integrate GoPlus Token / Malicious Address API to retrieve security flags for discovered spender contracts.
- Test: Query GoPlus for discovered spender addresses and print security signals.

MILESTONE 8: Data Normalization
- What: Transform raw Alchemy and GoPlus payloads into clean internal domain models matching frontend expectations.
- Test: Run normalizer with mock/real data and validate output structure.

MILESTONE 9: Deterministic Correlation Engine
- What: Rule-based engine linking active approvals to spender contracts with detected security flags.
- Test: Run correlation rules and verify flagged exposures.

MILESTONE 10: Evidence Generation
- What: Build the step-by-step evidence chain:
  Wallet -> Approved Token -> Spender Contract -> Security Signal -> Potential Exposure.
- Test: Validate structured evidence object generation.

MILESTONE 11: Full /api/analyze Response Contract
- What: Wire pipeline into POST /api/analyze returning the exact AnalysisResult JSON schema.
- Test: Full end-to-end curl test with test address.

MILESTONE 12: Base Chain Support
- What: Extend the pipeline to query Base alongside Ethereum.
- Test: Verify multi-chain results array in response.

MILESTONE 13: Outlier & Anomaly Signals
- What: Add non-fatal warning flags (e.g., brand-new unverified contract or unusual allowance size).
- Test: Verify signals are categorized as "informational" or "attention" without false alarms.

MILESTONE 14: Frontend Integration
- What: Update frontend/lib/api.ts to fetch from http://localhost:4000/api/analyze.
- Test: Search in browser UI and see live backend results populated into tabs.

MILESTONE 15: Final Testing & Demo Fixtures
- What: Prepare verified walkthrough addresses for hackathon judging demo.
- Test: Run full demo flow from landing to results to evidence view.
